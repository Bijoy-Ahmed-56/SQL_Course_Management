# SQL Course Management System & Experiments

This repository contains database management projects, experiment reports, and SQL scripts developed as part of coursework. It covers database creation, table design, data manipulation, and advanced SQL operations using **MySQL** and **MySQL Workbench**.

---

## 📁 Repository Structure & Contents

- **`Exp1(3).doc`**: Experiment 1 report focusing on basic database operations, table creation (`Course`, `Teacher`, `Course_take`), and inserting constrained data[cite: 3].
- **`Exp2.doc`**: Experiment 2 report covering SQL data manipulation, single-table queries, multi-table joins, nested queries, subqueries, and data updates/deletions[cite: 4].
- **`Exp3.doc`**: Experiment 3 report demonstrating SQL Data Definition, creating and querying views, updating views, and managing student-course records[cite: 5].
- **`Experiment-3.sql`**: SQL script file containing queries and commands tested during the experiments.
- **`Create student DB-nf.txt`**: Batch script and text file used for setting up the student database schema and tables.
- **`course_management.sql`**: SQL script for managing course and teacher schemas.

---

## 🚀 Key Topics Covered

1. **Basic Operations & DDL:** Creating databases, defining tables, setting primary/foreign keys, and enforcing constraints (e.g., `CHECK`, `NOT NULL`)[cite: 3, 5].
2. **Data Query Language (DQL):** Filtering data, pattern matching, aggregate functions (`COUNT`, `SUM`, `AVG`), and grouping (`GROUP BY`, `HAVING`)[cite: 4].
3. **Joins:** Combining multiple tables using `INNER JOIN`, `LEFT JOIN`, and complex multi-table relationships[cite: 4].
4. **Subqueries & Nested Queries:** Utilizing subqueries for advanced filtering, score comparisons, and set operations (`IN`, `NOT IN`, `EXISTS`)[cite: 4].
5. **Views:** Creating, querying, updating, and modifying database views for data abstraction and security[cite: 5].
6. **Data Manipulation Language (DML):** Inserting, updating, and deleting records safely with transactional integrity[cite: 4, 5].
