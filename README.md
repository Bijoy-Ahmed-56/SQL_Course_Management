# SQL Course Management System Project

**University Database Assignment**

This repository contains the database schema, SQL scripts, and lab report for the Course Management System university assignment.

## Project Overview

The objective of this project is to design and implement a structured relational database using MySQL to manage university courses, teachers, and related academic records.

### Key Components:

- **Database Schema**: `Course_management`
- **Tables Created**:
  - `Course` (Stores course details, credits, semesters, and types)
  - `Teacher` (Stores faculty and instructor information)
- **SQL Scripts**: Contains standard DDL (`CREATE DATABASE`, `CREATE TABLE`) and constraints (`PRIMARY KEY`, `CHECK` constraints).

## Project Files

- `course_management.sql` - Main SQL script containing database creation and table definitions.
- `Exp1(3).doc` - Detailed lab report and documentation for the assignment.

## How to Run / Execute

1. Open **MySQL Workbench** or any MySQL-compatible client.
2. Import or copy-paste the queries from `course_management.sql` and execute them to set up the database and tables.
