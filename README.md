# SQL Course Management

A collection of SQL coursework experiments and database management exercises using MySQL. This repository includes SQL scripts and experiment reports covering database design, queries, data manipulation, joins, subqueries, and views.

## Repository Contents

| File | Description |
|---|---|
| `Exp1(3).doc` | Experiment 1 report covering database creation, table design, and basic SQL operations |
| `Exp2.doc` | Experiment 2 report covering data manipulation, queries, joins, and subqueries |
| `Exp3.doc` | Experiment 3 report covering SQL views and student-course database operations |
| `Experiment-3.sql` | SQL script for creating and populating the student database |
| `Create student DB-nf.txt` | Student database setup script and related notes |
| `course_management.sql` | SQL script for course management database operations |

## Topics Covered

- **Database Design:** Database and table creation
- **Constraints:** Primary Key, Foreign Key, NOT NULL, and CHECK
- **SQL Queries:** Filtering, sorting, and retrieving records
- **Aggregate Functions:** COUNT, SUM, AVG, and grouping
- **Joins:** Combining data from multiple tables
- **Subqueries:** Nested queries and conditional filtering
- **Views:** Creating, querying, and updating database views
- **Data Manipulation:** INSERT, UPDATE, and DELETE

## Tools & Technologies

- **DBMS:** MySQL
- **Database Tool:** MySQL Workbench
- **Language:** SQL

## Purpose

This repository documents my practical learning and coursework in SQL and relational database management. It serves as a collection of database experiments, SQL scripts, and query practices.
